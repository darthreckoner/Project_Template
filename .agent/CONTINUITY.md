# Continuity

Status: Template

This is the starter continuity entry point. In a derived project, replace this
text with its current scope, accepted decisions, open work, verification, and
next action. Keep one continuity record and load supporting material by topic.

- Begin project setup with [Profile Selection](../docs/PROFILE_SELECTION.md) and
  [Project Brief](../docs/PROJECT_BRIEF.md). Declare application validation before
  introducing executable application code.
- Use the [workflow-improvement planning prompt](../docs/codex_workflow_improvement_prompt.md)
  only when explicitly requested. It supports source templates and incremental
  adoption in new or existing projects; it does not activate a workflow or pilot.
- Use [context maintenance](../.agents/skills/context-maintenance/SKILL.md) for
  requested context audits or cleanup.
- No project plan or experiment is active in this starter. Source-template
  maintenance approvals and closure evidence remain in its Git history.
