## Lifecycle

- Create new ADRs from `ADR-TEMPLATE.md` in `proposed/` with `Status: Proposed`.
- Only a human may approve the decision and move it to `accepted/` with `Status: Accepted`.
- Rejected or superseded ADRs remain in `proposed/` with `Status: Rejected` or
  `Status: Superseded`; no third lifecycle directory is used.
- Update this table in the same change as an ADR state or summary change.

Accepted ADRs are project truth. Proposed, Rejected, and Superseded ADRs are historical/proposal
context, not accepted authority.
