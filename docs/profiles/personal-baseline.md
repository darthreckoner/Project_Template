# Personal Baseline Profile

This profile is the concise first-use path for solo, exploratory, bounded, or low-risk projects.

## Required records

- `docs/PROJECT_BRIEF.md` with an explicit `Selected profile: Personal Baseline`.
- Exact application validation commands in `docs/DEVELOPMENT_WORKFLOW.md` and the matching CI step
  before executable application code is merged.
- Applicable security choices recorded as `Enabled`, `Not supported`, or `Not applicable` with a
  reason.

Vision, Requirements, and Architecture remain available, but are created when a planning trigger,
material uncertainty, or durable intent decision makes them necessary.

## Escalation

Escalate to Governed Engineering for persistent state, architecture, external contracts,
security/trust boundaries, production use, collaboration, or any other Level 2 trigger. Record the
decision in the Project Brief before proceeding.
