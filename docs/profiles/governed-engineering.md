# Governed Engineering Profile

This profile is for shared, long-lived, externally integrated, sensitive, or materially
consequential projects.

## Required records

- A completed Project Brief selecting Governed Engineering.
- Human-approved `docs/VISION.md`, accepted `docs/REQUIREMENTS.md`, and current `docs/ARCHITECTURE.md`.
- A completed governed bootstrap checklist with GitHub and security capability states recorded.
- The normal plan and ADR lifecycle, including human approval for protected transitions.
- Exact application validation commands and the matching CI step before executable code is merged.

## Activation

Derive these records from the Project Brief without deleting approved scope or non-goals. Preserve
unknowns as unknowns, record unsupported controls explicitly, and link the activation decision back
to the brief.
